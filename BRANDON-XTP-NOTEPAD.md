# Brandon's XTP Quick Notepad

Use this as the fast-reference version. The interactive version is `xtp/notepad.html`.

## North Star

**Yeet/XTP wedge:** safest place to gamble in crypto for serious players.

Do not default to “bigger bonus.” The stronger angle is trust + VIP treatment + proof.

## First Month Goals

1. **Learn the machine** — who owns VIP, product, payments, compliance, creators, affiliates, support.
2. **Find the leaks** — KYC friction, withdrawal anxiety, weak VIP handoff, unclear comp structure, creator conversion gaps.
3. **Ship useful assets** — small docs/pages/scripts the team can actually use.
4. **Build credibility** — be the guy who brings signals, not vague ideas.

## Daily Operating Loop

### Morning
- Pick one internal person to learn from.
- Pick one competitor/player signal to investigate.
- Pick one concrete artifact to ship or improve today.

### Midday
- Turn raw notes into a usable asset: table, checklist, script, page brief, lead list, or one-page recommendation.

### End of Day
- Send a tight update:
  - What I looked at
  - Signal found
  - Recommended action
  - What I can own next

## Quick Reference

### Core Positioning
- Safest place to gamble in crypto
- Serious players, not bonus tourists
- Listed group / audited / segregated-funds trust angle
- Whales comfortable leaving meaningful balances

### VIP Migration Funnel
- Tier-match from Stake / Rollbit / Roobet / Shuffle
- Dedicated VIP manager
- Priority withdrawals
- Custom cashback/lossback rules
- Telegram/Signal concierge handoff
- Internal qualification rules

### Trust UX Assets
- Trust center: license, reserves, audits, fairness, withdrawals
- Withdrawal proof wall
- Median withdrawal time block
- “Why serious players switch” page
- Provably fair explainer that normal users can understand

### Competitor Intel Sources
- Replies under Stake / Roobet / Rollbit / Shuffle tweets
- Reddit complaint threads
- Telegram / Discord groups
- Creator chat comments
- Public VIP complaints

### Signals Worth Saving
- Withdrawal delays
- KYC blocks/confusion
- VIP host complaints
- Geo restriction issues
- Weak reward treatment
- Large bet slips / balance screenshots
- Public usernames or handles

### Lossback Guardrails
- Formula: lossback payout = lossback % × net losses
- Risk: low-edge games + promo hunters
- Use weekly caps, tier eligibility, game weighting, abuse review
- Avoid hard withdrawal SLAs unless ops can truly hit them
