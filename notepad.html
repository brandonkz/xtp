Core Wedge

Yeet should not try to be a louder Stake.

  • Safest place to gamble in crypto
  • Built for serious players, not bonus tourists
  • Listed group / audited / segregated-funds trust angle
  • Where whales feel safe leaving real balances

First Month Outcomes

  • Know who owns VIP, product, payments, compliance, affiliates, creators.
  • Ship 2-3 useful docs the team can actually use.
  • Build a competitor complaint / VIP lead tracking habit.
  • Find one painful funnel leak: KYC, withdrawals, VIP response, onboarding.

VIP Migration Funnel

  • Tier-match from Stake / Rollbit / Roobet / Shuffle.
  • Dedicated VIP manager + priority withdrawals.
  • Custom cashback/lossback rules with caps.
  • Concierge handoff via Telegram / Signal.

Trust UX Assets

  • Trust center: licensing, reserves, audits, fairness, withdrawals.
  • Withdrawal proof wall: screenshots, timestamps, big wins paid.
  • Median withdrawal time block.
  • “Why serious players switch” comparison page.

Daily Competitor Intel

  • Scan Stake / Rollbit / Roobet / Shuffle / BC.GAME complaints.
  • Capture handles with pain + value signal.
  • Tag: withdrawal, KYC, VIP host, geo, comp, bonus.
  • Turn high-signal pain into tailored outreach or product insight.

Lossback Guardrails

  • Formula: lossback payout = % × net losses.
  • Risk: low-edge games + promo hunters can drain value.
  • Use weekly caps, tier eligibility, game weighting, abuse review.
  • No hard SLA promises unless ops can hit them.

  • Where do high-value players drop off?
  • What claims can we legally/provably make?
  • Who can approve landing pages, offers, and outreach?
